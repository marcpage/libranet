    The nodes of a network keep a ledger of Karma together: a chain of blocks, a generation at a time, each generation's transaction block holding the payments put up, and its validation block the stakes on it. Each identity's Karma, a person's or a node's, is its balance as the chain this node follows states it at its head, with the head's reward paid, the same on every node following that chain. A Karma is 100,000,000,000,000 Kismet; hover over an amount for its Kismet. In a browser on the node's own machine, whoever is signed in pays others through the node, which signs the payment as them, and stakes on the latest full block, sharing the reward should a validation block holding the stake win. A link to /karma/?id= and an identity's id shows its Karma, and one to /karma/?block= and a validation block's id shows that block alone: who stakes on the transaction block it validates, and how much, that block's transactions and the balances it states, and a link to the block before it.
