Its addresses

Each node is listed by what it says of itself, kept at the drop node: and its id, signed by it, and shown by its name, or by its id, the content id of its public key, if it gives none. In a browser on the node's own machine, the list is what the node knows of each other node: whether a connection to it is open now, and which way, outbound if this node dialed it and inbound if it dialed this node, and what this node has counted of it, over all time. Elsewhere, it is the node list this node gives other nodes, of the nodes to try. Each node's mark is from the scores the node builds from your trust list, the lists of those you trust, and so on onward: 🟢 above 0, trusted; 🟡 0, neither; 🔴 below 0, distrusted; and ⚪ where there are no scores to show. A link to /nodes/?id= and a node's id shows it alone, with its addresses.
