What is served here

Anyone may propose a bundle for any path beneath /chaos, by placing a proposal at the drop of the path, or of a directory above it: chaos:/ for the root, then chaos:/ and each element of the path in turn. A bundle proposed at a level serves the paths beneath it that it holds, so it must hold the rest of the path below that level. The node first looks at every level for proposals signed by someone trusted, from the root down, and then for those whose signer is neither trusted nor distrusted, or that are unsigned. At each level it takes the newest first, and serves the first whose bundle holds the rest. A distrusted signer's proposal is never served. Whose trust chooses is whoever is signed in, or else this node's. Each signer's mark is from those scores: 🟢 above 0, trusted; 🟡 0, neither; 🔴 below 0, distrusted; and ⚪ where there are no scores to show. Ending any address beneath /chaos with ? shows this page for it.
