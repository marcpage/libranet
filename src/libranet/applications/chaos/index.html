What is served here

Upload a zip

The zip's contents are put at the address chosen, signed by you, and served there to whoever trusts you more than anyone uploading there too. A zip of one folder gives that folder's contents.

Anyone may upload a bundle to any path beneath /chaos, by placing an upload at the drop of the path, or of a directory above it: chaos:/ for the root, then chaos:/ and each element of the path in turn. A bundle uploaded at a level serves the paths beneath it that it holds, so it must hold the rest of the path below that level. The node first looks at every level for uploads signed by someone trusted, from the root down, and then for those whose signer is neither trusted nor distrusted, or that are unsigned. At each level it takes the newest first, and serves the first whose bundle holds the rest. A distrusted signer's upload is never served. Chaos is only for someone signed in, and their trust chooses. Each signer's mark is from those scores: 🟢 above 0, trusted; 🟡 0, neither; 🔴 below 0, distrusted; and ⚪ where there are no scores to show. Ending any address beneath /chaos with ? shows this page for it.
